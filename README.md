# LifeOperatingSystem

A minimal personal dashboard: clock and Hamburg weather, Focus timer, tasks, school timetable and homework. Works in the browser and installs as an app (PWA) on phone and laptop.

Plain HTML/CSS/JS — no build step. Open `index.html` through any static server, or use the GitHub Pages site.
